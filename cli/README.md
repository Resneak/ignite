# Ignite CLI

## Developers
* Check `DEVELOPERS.md`

## Running
1. `npm i` 
2. `npm run start-dev`

## Example Profiles and Proxies
* Located in `ignite-cli/development/`

## Building via [pkg](https://www.npmjs.com/package/pkg)
* `npm run build` - this will output executables to the `/build` directory
* See [pkg readme](https://github.com/vercel/pkg) to support more operating systems
